# Kaiju Kings — Godzilla vs King Ghidorah (Fabric 1.20.1)

## วิธีรัน/สร้างมอด
1. ติดตั้ง JDK 17 + Gradle 8.x (หรือเปิดโฟลเดอร์นี้ด้วย IntelliJ แล้วให้ import Gradle)
2. รัน `gradle build` -> ไฟล์มอดอยู่ที่ `build/libs/kaiju-kings-1.0.0.jar`
3. ใส่ jar ลงโฟลเดอร์ mods พร้อม **Fabric API 0.92.2+1.20.1** (Minecraft 1.20.1 + Fabric Loader)
ทดสอบในเกม: `gradle runClient`

## วิธีเล่น
- คราฟเข็มทิศ: เข็มทิศ + เพชร + มรกต = เข็มทิศก็อตซิลลา / เข็มทิศ + เพชร + บล็อกทอง = เข็มทิศคิงกิโดร่า
  ถือไว้แล้วเข็มจะชี้ไปที่ถ้ำของมัน (ทุกๆ ~700 บล็อก) เมื่อเข้าใกล้ ~70 บล็อก มันจะตื่น
- ฆ่ามันจะดรอปเซลล์ 40-64 ชิ้น -> คราฟชุดเกราะ (หมวก 5 / เสื้อ 8 / เกราะขา 7 / รองเท้า 4 เซลล์)
- ใส่ครบ 4 ชิ้น = เสริมพลังโจมตี/ป้องกัน/ทนไฟ (ก็อตซิลลา: ฟื้นเลือด, คิงกิโดร่า: บินได้)
- ใช้ท่า: ถือเซลล์ของเผ่านั้น **คลิกขวา = ท่า 1**, **กด Shift + คลิกขวา = ท่า 2** (มีคูลดาวน์)
  - ก็อตซิลลา: ลำแสงอะตอมมิกจากปาก / ระเบิดอะตอมมิก
  - คิงกิโดร่า: กราวิตี้บีม (ยกตัวลอย) / พายุฟ้าผ่า
- ไข่เสก (Spawn Egg) อยู่ในแท็บ Spawn Eggs ไว้ทดสอบให้สองตัวสู้กัน
- ก็อตซิลลาและคิงกิโดร่าจะโจมตีกันเองอัตโนมัติเมื่ออยู่ในระยะ

## ขนาด
- ก็อตซิลลา สูง 90 บล็อก (กว้าง 30) / คิงกิโดร่า สูง 136 บล็อก (กว้าง 80) บินได้ทะลุภูมิประเทศ
- ก็อตซิลลาเดินตรงเข้าหาเป้าหมายและพังบล็อกที่ขวางทาง (ปิดได้ด้วย gamerule mobGriefing false)
- ควรเล่นที่ render distance สูงๆ เพราะตัวใหญ่มาก

## วงจรชีวิตคิงกิโดร่า
1. อุกกาบาตตกลงมาจากฟ้า (ล่องหนมีแต่ลูกไฟ) ระเบิดเป็นหลุมใหญ่ตอนชน
2. ตื่นขึ้นมาแบบ **หัวเดียว** (อ่อนแอกว่า ยิงกราวิตี้บีมได้หัวเดียว ไม่มีพายุ)
3. พอผ่านไป ~75 วิ หรือเลือดเหลือ 70% มันบินพุ่งขึ้นฟ้า มีฟ้าผ่าตาม
4. หายเข้าไปในก้อนเมฆ ได้ยินเสียงคำรามและฟ้าร้อง ~12 วิ
5. กลับมาพร้อมเลือดเต็ม **หัวที่ 2 และ 3 ค่อยๆ งอกออกมา** แล้วใช้ท่าครบ (กราวิตี้บีม 3 หัว + พายุฟ้าผ่า)
(ไข่เสกคิงกิโดร่าจะเกิดเป็นร่าง 3 หัวเต็มทันที เอาไว้ทดสอบ)
